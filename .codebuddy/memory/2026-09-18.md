## [P1-4:安全+UX] 前端 Markdown 渲染加固：修掉 2 个 XSS 缺口 + 补上表格/代码高亮

- **问题**: 审核报告只记了 1 个点（D9 属性逃逸），勘察后发现实际是 **3 处渲染点 + 2 类安全缺口 + 1 处样式静默失效**
- **修复**: 新增统一模块 `packages/frontend/src/utils/markdown.ts`（markdown-it + highlight.js + DOMPurify）
- **状态**: ✅ 完成并发布 v0.6.29（后续建议见 `docs/67` §七）

### 发现的两个真实 XSS 缺口（原自研正则渲染器）
```ts
// 原本只转义 & < >，漏了 "，且 URL 协议完全不过滤
let html = text.replace(/&/g,'&amp;').replace(/</g,'&lt;').replace(/>/g,'&gt;');
html = html.replace(/\[([^\]]+)\]\(([^)]+)\)/g, '<a href="$2" ...>$1</a>');
```
| # | 缺口 | 攻击样例 |
|---|------|---------|
| ① | `"` 未转义 → 属性逃逸 | `[链接](x" onmouseover="alert(1))` |
| ② | **URI 协议完全不过滤** | `[点我](javascript:alert(1))` **点击即执行**（比 ① 更直接） |

另发现：`PluginsMarket` 把 **GitHub 远程 README 裸 HTML** 直接塞进 `dangerouslySetInnerHTML`，**完全无消毒**；
且它用的 `prose prose-invert` 依赖 `@tailwindcss/typography`，而**项目并没装** → README 一直无排版（与 P0-5 令牌断裂同类病灶：引用不存在的定义且不报错）。

### 选型理由
- **markdown-it**（`html:false` 默认转义 + 原生表格 + v15 自带类型）而非 marked
- **highlight.js** 而非 shiki：markdown-it 的 `highlight` 钩子是**同步**的，shiki 需异步加载 WASM → 得不偿失
- **DOMPurify** 只用于远程 HTML；本地 Markdown 不重复消毒（聊天列表虚拟滚动高频渲染，没必要）

### 测试：35 条（含 6 条 🛡️ 安全回归）
原始 HTML 转义 / img onerror / `javascript:` / `data:` / 属性逃逸 / 大小写变形协议 + 表格、有序列表、嵌套列表、8 组语言别名。
