## 一、全局错误处理中间件（`middleware/errorHandler.ts`）

### 1.1 统一错误响应格式（/api/*）

```json
{ "success": false, "error": { "code": "SESSION_NOT_FOUND", "message": "资源不存在" } }
```

| 规则 | 说明 |
|------|------|
| 状态码 | 取 `err.statusCode ?? err.status`；非法值（非 4xx/5xx）回退 500 |
| 错误码 | 优先 `err.code`（≤64 字符）；否则按状态码映射（BAD_REQUEST/UNAUTHORIZED/FORBIDDEN/NOT_FOUND/RATE_LIMITED/INTERNAL_ERROR） |
| message | **4xx 原文返回**（调用方参数/权限问题，原文最有用）；**5xx 固定友好提示**（内部细节只进日志） |
| 安全 | 错误堆栈只进日志（method/path/stack），**绝不进响应体** |
| headersSent | 流式响应中途出错 → 只 `end()` 收尾，不重复写响应头（否则 `ERR_HTTP_HEADERS_SENT`） |
| 非 /api 路径 | 纯文本 500（避免反向出现"HTML 被 JSON 解析"问题） |

### 1.2 `asyncHandler()` —— Express 4 异步路由必读

**Express 4 不会捕获 async 路由的 rejection**（会变成 unhandledRejection + 请求悬挂无响应）。
新增/修改 async 路由必须包裹：

```ts
app.get('/api/x', asyncHandler(async (req, res) => { ... }));
```

> 存量 93 条路由中 async 路由多为手写 try-catch，不强制回改；新代码一律用 asyncHandler。

### 1.3 注册位置（顺序契约）

```ts
registerStaticRoutes(app, {...});  // 最后的路由注册
app.use(errorHandler);             // ← 错误中间件在其后（Express 只捕获之前注册的路由抛的错）
```

404 兜底在 staticFiles 的正常响应流，与错误流互不干扰。

## 二、CI 冒烟测试（`scripts/smoke-test.mjs` + ci.yml `smoke-test` job）

| 项 | 内容 |
|----|------|
| 触发 | `tests` job（全部单测）通过后 |
| 步骤 | pnpm install → 构建 core+server → `node scripts/smoke-test.mjs` |
